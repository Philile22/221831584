Student Performance Analytics Dashboard

Project Title

ByteMe — a web-based system that collects, analyses and visualises student academic data to help lecturers identify struggling students early.

Project Overview

Our team, ByteMe, proposes to build a data-driven dashboard that allows educators to monitor student performance across multiple modules. The system will use modern web technologies for the front-end and a relational database for storing and querying academic records. Insights will be displayed through interactive charts and reports.

Project Objectives

  1. Design a clean, responsive user interface for lecturers.
  2. Store student records securely in a relational database.
  3. Generate visual reports of performance trends.
  4. Send early alerts for students at risk of failing.
  5. Deploy the system on a public web host for demonstration.

Technologies We Will Use

  • Front-end: HTML, CSS, JavaScript
  • Back-end: PHP and Java (JSP)
  • Database: MySQL
  • Server: Apache HTTP Server and Apache Tomcat
  • Version Control: Git and GitHub
